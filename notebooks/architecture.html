Feature-Conditioned Learnable Context for Compositional
Zero-Shot Radar Jamming Signal Classification
A CoOp-style architecture that injects multi-domain signal features into a frozen text encoder via domain-aware Meta-Nets

1. Architecture Overview

Figure 1. Overall architecture of the Feature-Conditioned Learnable Context framework. The visual encoder (left, partially unfrozen) maps STFT spectrograms to image features. Five domain-aware Meta-Nets (center, trainable) transform the 22-dimensional multi-domain signal features into 10 continuous context vectors, which are injected into the frozen text Transformer (right) before the class-name token embeddings. The contrastive objective aligns the two modalities in a shared embedding space.

2. Text Encoder with Context Injection

Figure 2. Detail of context injection into the text encoder. The 10 context vectors (color-coded by domain) are inserted between the SOT token and the class-name embeddings. The EOT extraction position is shifted by M=10 to account for the inserted context tokens.

4. Formulation

For each signal sample i with multi-domain feature vector f(i) = [ftime; ffreq; fbisp; fwav; fstat] ∈ ℝ22, the domain-aware Meta-Nets generate M = 10 context vectors:

Vd = MLPd(fd) ∈ ℝnd × D,    V = [Vtime; Vfreq; Vbisp; Vwav; Vstat] ∈ ℝ10 × D

where nd is the number of context tokens per domain and D is the transformer width. The text feature is then:

u = TextEnc([eSOT; V; ecls; eEOT]; θfrozen) ∈ ℝDe

The contrastive objective minimizes:

ℒ = −log exp(sim(vi,ui)/τ)⁄∑j exp(sim(vi,uj)/τ)   where  sim(v, u) = v⊤u / (‖v‖·‖u‖)

Only the Meta-Net parameters {MLPd}d=15 and the last 2 vision layers are updated; the text Transformer remains frozen.

5. Training & Evaluation Commands

5.1 Compute Feature Normalization Statistics

# Step 1: Compute mean/std for each of the 22 features from the training split python -m multi.compute_feature_stats \ --config multi/config.yaml \ --output multi/feature_normalization_stats.json

5.2 Training

# Step 2: Train with feature-conditioned context enabled # - Set use_feature_context: true in config.yaml first python -m multi.train_unified \ --config multi/config.yaml # The config.yaml must contain: # use_feature_context: true # n_ctx_per_domain: # time: 2 # 5-dim → 2 context tokens # freq: 2 # 4-dim → 2 context tokens # bispectrum: 1 # 2-dim → 1 context token # wavelet: 3 # 8-dim → 3 context tokens # statistical: 2 # 3-dim → 2 context tokens # feature_norm_stats_path: "multi/feature_normalization_stats.json" # prompt_lr: 0.002 # Meta-Net learning rate (~200× base lr)

5.3 Evaluation (Zero-Shot)

# Step 3: Evaluate with per-sample feature-conditioned text features python -m multi.evaluate_unified \ --config multi/config.yaml \ --checkpoint checkpoints/czsl_best.pt
Note: When use_feature_context: true, text features cannot be pre-cached because they depend on per-sample features. During evaluation, text features are computed on-the-fly for each sample across all candidate classes. Set use_feature_context: false to revert to the original caching behavior.

7. Key Design Choices

DesignRationaleImplementation
Domain-aware Meta-Nets Features from different signal processing domains have distinct scales, semantics, and dimensionality; a single monolithic network would conflate heterogeneous statistics. 5 independent 2-layer MLPs, each mapping domain-specific features to nd context tokens of dimension D.
Zero initialization At training onset the context vectors are near-zero, making the text encoder output approximately equal to the pretrained representation, ensuring training stability. The last Linear layer of each Meta-Net is initialized with zeros (weight and bias).
Context before class name Following CoOp, continuous context tokens are placed between SOT and class name embeddings, allowing the frozen Transformer to attend to both context and class tokens when producing the EOT representation. Sequence: [SOT | V1…VM | class_embs | EOT | pad]. EOT extraction index shifted by M.
Differential learning rates Meta-Net parameters are trained from scratch and require faster convergence, while the vision encoder retains pretrained knowledge that should be fine-tuned conservatively. Two AdamW parameter groups: prompt_lr = 2e-3 (Meta-Net), base_lr = 1e-5 (vision), weight_decay = 0 for Meta-Net.
